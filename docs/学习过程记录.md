### 核心要点

**1. 图片 → Patches → Tokens**
- 224×224 图片，切成 16×16 patches → 14×14 = 196 个 patch
- 每个 patch 拉直为 768 维向量（3×16×16 像素值）
- 通过 Patch Embedding（一个 Linear 层）映射到 Transformer 工作维度（如 1024 维）
- 这 1024 维是**学习到的特征**，不是原始像素，模型自己学会从杂乱像素中提炼有用信息

**2. 位置编码**
- Self-Attention 是排列不变的（交换 token 顺序结果不变），必须注入位置信息
- V-JEPA 默认使用 **RoPE（旋转位置编码）**：在 Attention 计算时通过旋转 query/key 向量来编码位置
- RoPE 优势：自然支持变长/变分辨率输入

**3. 从 2D 图片到 3D 视频**
- 视频多了时间维度：(3, T, H, W)
- PatchEmbed3D：空间上切 16×16，时间上用 tubelet_size=2
- 16 帧输入 → 8 个时间步 × 14×14 = **1568 个 token**

**4. Transformer Block**
- 每个 block：LayerNorm → Multi-Head Self-Attention → 残差连接 → LayerNorm → MLP (SwiGLU) → 残差连接
- Self-Attention：每个 token 问所有其他 token "你和我的内容相关吗？"
- ViT-L 有 24 层，ViT-g 有 40 层

**5. ViT 在 V-JEPA 中的角色**
- Encoder 就是一个 ViT，只处理**可见的 token**
- 输出的特征传给 Predictor，Predictor 用可见特征预测被遮罩区域的特征

### 讨论过的重点问题
- 196 个 token 的计算：224÷16=14 个/边，14×14=196
- 每个 token 的 tensor 形状：(196, 1024) — 196 个 token，每个 1024 维
- 原始像素作为 token 是否太杂乱 → 实际输入 Transformer 的是**经过 Linear 层提炼后的特征**，不是原始像素
- 16 帧是否每一帧都必要 → V-JEPA 通过**遮罩策略**迫使模型只抓关键信息，训练模型像人一样稀疏地理解视频
- ViT 命名规范：B=Base(86M)、L=Large(300M/24层)、H=Huge(630M)、g=giant(1B/40层)、G=Gigantic(2B/48层)。字母越往后参数量越大，层数、向量维度、注意力头数同步增加

#### 补充概念

**6. EMA（指数移动平均）**
- Target Encoder 通过 EMA 从 Online Encoder 缓慢复制参数：`param_target = 0.99925 × param_target + 0.00075 × param_online`
- 作用：提供一个稳定的目标，防止模型坍塌
- 类比：学生对错题快速调整（online），老师通过长期观察稳定吸收（target）

**7. L1 vs L2 Loss**
- L1 = 绝对值误差，L2 = 平方误差
- L2 对大误差极度敏感，L1 更鲁棒
- V-JEPA 选择 L1：特征空间可能出现异常值，L1 避免异常维度主导梯度

#### 讨论过的重点问题
- EMA 全称：Exponential Moving Average（指数移动平均）
- 为什么需要两个编码器：防止模型「作弊」——如果自己预测自己，会坍塌到恒定输出
- 为什么 V-JEPA 选 L1：特征空间预测的本质需求——对异常值不敏感、训练更稳定
